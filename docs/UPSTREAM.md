# 출처와 라이선스

이 프로젝트의 제품 표기는 **SDStudio · Cupcake 포크**입니다. 원작 SDStudio와 구분하면서도 원작의 이름과 출처를 알 수 있도록 했습니다.

| 구성요소 | 출처 | 라이선스 |
| --- | --- | --- |
| SDStudio | [sunho/SDStudio](https://github.com/sunho/SDStudio) | [MIT](../LICENSE) |
| 이어받은 SDStudio 변경 사항 | [Dd154663/SDStudio](https://github.com/Dd154663/SDStudio) | MIT |
| Cupcake 수정 사항 | [ruyari-cupcake/sdstudio-cupcake](https://github.com/ruyari-cupcake/sdstudio-cupcake) | MIT |
| Capacitor background mode | Raso Angelo, `externals/capacitor-background-mode`의 패키지 정보와 원본 문서 | 패키지에 표시된 MIT |
| Noto Sans 폰트 | [Noto Project](https://github.com/notofonts/noto-fonts) | SIL Open Font License 1.1 |

원래 저작권 고지를 보존합니다. [SDStudio MIT 원문](../assets/SDStudio-LICENSE.txt), [외부 구성요소 안내](../assets/THIRD_PARTY_NOTICES.txt), [Noto 폰트 OFL 원문](../assets/fonts/OFL.txt)은 프로그램 배포에도 함께 포함됩니다. npm 의존성은 각 패키지의 라이선스를 따릅니다.

이 저장소는 현재 공개 소스부터 기록합니다. 원작과 다른 점은 파일 내용과 [변경 안내](CUPCAKE_CHANGES.md)를 비교해 확인해 주세요.

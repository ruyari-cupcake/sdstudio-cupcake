# 예전 감정·포즈 씬과 프롬프트 조각 가져오기

6.1.1-cupcake.1부터 예전 프로젝트 JSON과 현재 씬 템플릿 JSON을 같은 씬 템플릿 관리 화면에서 불러올 수 있습니다. 공개 버전과 비공개 버전에 같은 가져오기 기능을 제공합니다.

## 파일의 종류

| 파일 내용 | 의미 | 가져오는 곳 |
| --- | --- | --- |
| `scenes`, `presets`, `library`가 있는 프로젝트 JSON | 감정·포즈별 씬, 생성 프리셋, 로컬 조각을 담은 작업 묶음 | 프로젝트 파일 불러오기 또는 씬 템플릿의 파일 불러오기 |
| `type: "sdstudio-scene-template"`인 JSON | 현재 버전에서 내보낸 재사용 씬 템플릿 | 씬 템플릿의 파일 불러오기 |
| `name`, `pieces`가 있는 조각그룹 JSON | 프롬프트에서 `<그룹.이름>`으로 참조하는 재사용 문구 | 프롬프트조각의 불러오기 |

감정 이름이 많이 들어 있어도 파일 전체가 조각그룹인 것은 아닙니다. 씬 묶음과 조각그룹은 역할이 다르므로 각 관리 화면에서 가져옵니다.

## 감정·포즈 씬을 현재 프로젝트에서 쓰기

1. 사용할 프로젝트를 엽니다.
2. 씬 도구 모음의 **⋯ → 씬 템플릿**을 엽니다.
3. **파일 불러오기**에서 예전 프로젝트 JSON 또는 씬 템플릿 JSON을 선택합니다. 파일 출처를 묻는 경우 **파일**을 선택합니다.
4. **현재 프로젝트로 복사**를 누르고 방금 불러온 템플릿을 고릅니다.
5. 같은 이름의 씬이 있으면 번호를 붙여 추가, 기존 씬을 휴지통으로 옮긴 뒤 덮어쓰기, 겹치는 씬 건너뛰기 중 하나를 선택합니다.

템플릿 목록의 이름을 누르면 템플릿 자체를 열어 수정할 수 있습니다. **현재 프로젝트로 복사**는 선택한 프로젝트에 씬을 추가하는 동작입니다.

씬이 참조하는 로컬 조각그룹과 그 조각이 다시 참조하는 그룹도 함께 복사합니다. 현재 앱의 전역 조각에 의존하는 경우에는 실제로 사용되는 조각도 함께 보존합니다. 같은 이름의 그룹에 다른 내용이 있으면 새 이름을 붙이고 가져온 씬의 참조도 함께 바꿉니다. 기존 프로젝트의 조각 내용을 바꾸지 않습니다.

씬만 복사할 때는 대상 프로젝트의 생성 프리셋을 유지하며, 원본 프로젝트의 생성 결과 이미지나 프리셋 미리보기 이미지를 복제하지 않습니다. 원래 생성 프리셋까지 함께 사용하려면 전체 프로젝트로 불러오세요.

## 프로젝트 전체 또는 씬 설정만 가져오기

프로젝트 파일 불러오기나 JSON 파일 드롭으로 예전 프로젝트를 가져올 수 있습니다.

- **새 프로젝트로 불러오기**는 씬과 프리셋, 로컬 조각, 포함된 프리셋 미리보기를 함께 가져옵니다.
- **현재 프로젝트에 씬과 사용 중인 조각 불러오기**는 씬 설정과 필요한 조각을 가져옵니다. 같은 이름의 씬 설정을 덮어쓸 때는 먼저 확인하며, 현재 프로젝트에서 생성한 이미지와 이미지 선택은 유지합니다.

씬 설정에는 프롬프트, 해상도, 시드, 네거티브 프롬프트, 캐릭터 프롬프트와 워크플로별 씬 설정이 포함됩니다. 저장에 실패하면 성공으로 안내하지 않습니다.

## 조각그룹 가져오기

1. **프롬프트조각** 화면을 엽니다.
2. 이 프로젝트에서만 쓸 조각은 **로컬 조각**, 여러 프로젝트에서 공유할 조각은 **전역 조각**을 고릅니다.
3. **불러오기**로 조각그룹 JSON을 선택합니다. 같은 이름이 있으면 표시되는 충돌 처리 선택지를 확인합니다.

전체 프로젝트에 같은 조각그룹이 이미 포함되어 있다면 별도의 조각 파일을 다시 가져올 필요가 없습니다. 조각의 이름은 있지만 프롬프트가 빈 문자열이면 원본에 빈 값으로 저장된 것입니다. 가져오기 과정에서 임의의 내용을 채우지 않습니다.

## 파일을 알아보지 못할 때

확장자가 `.json`이면 운영체제가 JSON MIME 정보를 제공하지 않거나 `.JSON`처럼 대문자로 표시해도 처리합니다. 다른 종류의 JSON을 선택하면 맞는 가져오기 화면을 안내합니다.

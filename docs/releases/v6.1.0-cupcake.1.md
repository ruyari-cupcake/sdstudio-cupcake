# SDStudio · Cupcake 포크 6.1.0-cupcake.1

새 버전 알림과 프로그램 안에서 업데이트하는 기능을 추가했습니다. 이 공개 버전은 공개 릴리즈만 확인합니다.

- 시작할 때 새 버전이 있으면 한 번 물어봅니다.
- `일주일 동안 보지 않기`를 누르면 일주일 동안 알림을 숨깁니다.
- Windows 단일 실행파일·폴더 배포와 Android APK를 지원합니다.
- 다운로드한 파일을 확인한 뒤 업데이트합니다.

처음에는 아래 파일을 직접 설치해 주세요. 다음 버전부터는 앱에서 업데이트할 수 있어요. 기존 SDStudio와 따로 설치되며, 필요한 작업은 기존 앱에서 내보낸 뒤 이 앱에서 불러올 수 있어요.

| 파일 이름 끝부분 | 사용 방법 |
| --- | --- |
| `Windows-Portable.exe` | 내려받은 파일 실행 |
| `Windows-folder.zip` | 압축을 풀고 `SDStudio Cupcake.exe` 실행 |
| `Android.apk` | Android에서 열어 설치 |

[변경 내용](https://github.com/ruyari-cupcake/sdstudio-cupcake/blob/main/docs/CUPCAKE_CHANGES.md) · [소스와 라이선스](https://github.com/ruyari-cupcake/sdstudio-cupcake/blob/main/docs/UPSTREAM.md)

확인 범위: Windows 화면 조작·업데이트 파일 교체·복구와 Android 설치 파일의 빌드·서명을 검사했습니다. Android 실제 기기에서 설치를 마치는 과정은 아직 확인하지 않았습니다.

# SDStudio · Cupcake 포크 6.1.1-cupcake.1

예전 감정·포즈 씬 자료의 가져오기 호환성을 고치고, 공개·비공개 모두 Google 드라이브 앱 설정을 사용할 수 있도록 보완했습니다.

## 씬과 프롬프트 조각

- 예전 프로젝트 JSON도 **씬 템플릿 → 파일 불러오기**에서 추가한 뒤 **현재 프로젝트로 복사**할 수 있습니다.
- 씬이 쓰는 로컬 조각과 전역 조각 참조를 함께 보존합니다. 이름이 겹치면 가져온 쪽의 이름과 참조를 함께 정리합니다.
- 현재 프로젝트에 씬 설정을 가져올 때 시드·네거티브·캐릭터·워크플로 설정을 반영하며, 기존 생성 이미지와 선택은 유지합니다. 템플릿에서 기존 씬을 덮어쓰는 옵션은 원래 씬을 휴지통으로 보존합니다.
- JSON 파일의 형식 정보가 비어 있거나 확장자가 대문자인 경우도 처리합니다.
- 씬·조각의 저장 실패를 성공으로 안내하지 않으며, 읽기 전용 창·다른 창에서 편집 중인 프로젝트·동명 프로젝트의 가져오기 처리를 보완했습니다.

[파일 종류와 가져오는 위치](https://github.com/ruyari-cupcake/sdstudio-cupcake/blob/main/docs/legacy-assets-guide.md)

## Google 드라이브

공개판 빌드에서 Google 앱 설정을 강제로 비우던 처리를 제거했습니다. **환경설정 → 드라이브 → Google 앱 설정 불러오기**로 데스크톱 OAuth JSON을 저장하면 계정 연결을 시작할 수 있고, 앱을 다시 실행해도 설정이 유지됩니다.

이 배포에는 기본 Google OAuth 앱 등록값이 사전 포함되어 있지 않습니다. PC에서는 유효한 데스크톱 앱 설정이 필요하며, Android에서는 배포 패키지와 기존 서명의 Google Cloud 등록이 필요합니다. 앱 등록과 개인 Google 계정의 승인은 별도 단계입니다. [설정 안내](https://github.com/ruyari-cupcake/sdstudio-cupcake/blob/main/docs/google-drive-setup.md)

## 설치

6.1.0 이상에서는 현재 배포 채널의 앱 업데이트로 받을 수 있습니다. 직접 설치하려면 아래 파일을 사용하세요.

| 파일 이름 끝부분 | 사용 방법 |
| --- | --- |
| `Windows-Portable.exe` | 내려받은 파일 실행 |
| `Windows-folder.zip` | 압축을 풀고 `SDStudio Cupcake.exe` 실행 |
| `Android.apk` | Android에서 열어 설치 |

공개판의 설치 ID와 업데이트 저장소는 공개 채널을 유지합니다. 기존 SDStudio와 따로 설치되며, 필요한 작업은 기존 앱에서 내보낸 뒤 불러올 수 있습니다.

검증 범위에는 가져오기·저장·재시작, Google 앱 설정과 인증 시작·취소, Windows 파일 교체·복구 및 Android 빌드·서명 검사가 포함됩니다. 실제 Google 계정의 승인·드라이브 전송과 Android 실제 기기에서의 설치 완료는 이번 자동 검증 범위에 포함되지 않습니다.
